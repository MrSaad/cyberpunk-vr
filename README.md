# Cyberpunk VR

A neon-drenched cyberpunk city rendered with [Three.js](https://threejs.org/), built to be explored in virtual reality through WebXR-compatible headsets.

## Vision

- **Roam freely** through rain-slicked streets, towering megastructures, and glowing alleyways
- **VR-first** — designed for WebXR headsets (Meta Quest, Apple Vision Pro, etc.), with a desktop fallback
- **Runs in the browser** — no install required, just open the page and enter VR

## Tech

- [Three.js](https://threejs.org/) for rendering
- [WebXR Device API](https://immersiveweb.dev/) for headset support
